# Sustitucion-de-Liskov  

¿Cómo se implementa?

La clase Producto establece los atributos y métodos generales de las demás clases 

Las clases derivadas deben ser capaces de usar los métodos de la clase padre sin alterar el funcionamiento de dichos métodos ni el resultado esperado.   

Se usan las derivadas para acceder a metodos del padre.
